# Залишки старого дизайну

Стан на 2026-11-09 після міграції екранів із готовими мобільними макетами.

## Замінено

Лічильники Бібліотеки 26 і персоналізації 65 також інтегровані з API; генератор `readTiles` видалено. Окремі loading/error стани та серверні нулі описані в [контракті лічильників](RESOURCE_COUNTS_API_MAPPING.md).

Старі `SettingsScreen`, `FavoritesScreen`, `SaveToNotebookModal`, `ChatHistoryScreen`, `WorkspaceScreen`, `OverviewScreen` видалені. Нові реалізації використовують мобільну навігаційну панель, Inter, поля та рядки з макетів, safe areas і прокручування. `PageScaffold` та `AppShell` більше не обгортають ці екрани.

| Розділ | Основний маршрут | Старі посилання, що тепер лише перенаправляють |
| --- | --- | --- |
| Бібліотека | `/mobile/26` | `/space` видалений раніше, окремого екрана немає |

Оновлені переходи в shell, пошуку, діалозі облікового запису, інструментах розробника та збереженні обраного. Статичні вихідні знімки макетів залишені для простежуваності; `resourceRoutes` перетворює старі адреси у мобільні.

Налаштування, обране та вибір робочого простору зберегли API інтеграцію. Історія й архів зберегли поточну локальну поведінку старого `ChatProvider`: міграція дизайну не додає серверної синхронізації. Персоналізація залишається мобільною презентацією з незавершеними операціями домену.

Оновлення пошуку: `/search` використовує мобільну структуру та справжні серверні джерела; `/ui/search` лише перенаправляє сюди зі збереженням `q`. Бібліотека й shell ведуть на новий маршрут. Див. [контракт пошуку](SEARCH_API_MAPPING.md).

## Продуктові маршрути зі старим інтерфейсом, які залишилися

| Екран | Маршрут | Реалізація / використання |
| --- | --- | --- |
| Вхід | `/login` | `AuthScreen`, стара центрована форма; активна авторизація |
| Реєстрація | `/register` | `AuthScreen`; використовується для створення першого облікового запису |
| Переглядач сесії | `/ui/session-viewer` | `SessionViewerScreen`, стара панель вкладок; маршрут існує, переходи здебільшого в старих невикористовуваних компонентах |
| Перегляд файлу | `/ui/file-preview` | `FilePreviewScreen`, стара панель переглядача; доступний напряму та з переглядача сесії |

Shared dialogs `WorkspaceSheet` та `SessionActionsSheet` лишаються окремими спільними компонентами; це не видалені повносторінкові екрани. `WorkspaceSheet` уже використовує справжній API список і веде в мобільне меню налаштувань.

## Технічні сторінки

`/explore` і `/avatar-preview` зберігають `AppShell`. Це сторінки розробника.

## Заглушки у вебоболонці

Наступні адреси обслуговує `[...destination].tsx` усередині `AppShell`; це Retry / Unavailable, а не завершені екрани:

- `/calendar`, `/kanban`, `/co-writer`.
- `/space/journal`, `/space/questions`, `/knowledge-bases`, `/whisper`.
- `/agents`, `/space/personas`, `/space/skills`, `/space/mcp`, `/space/cli-apps`, `/memory`.
- `/partners` та відомі пошуку `/partners/partner-a`, `/partners/groups/group-a`.
- `/session-handoff`, `/admin/users`.
- `/settings/workspace`, `/settings/connections`, `/settings/llm`, `/settings/status`.

Мобільні презентації відповідних розділів можуть існувати окремо; ці заглушки не змінювалися в межах міграції семи обговорених екранів.

## Перевірка

Автоматичні перевірки охоплюють маршрути та кодування ідентифікаторів. Браузерні сценарії використовують локальні Postman stand-ins: налаштування — чернетки, застосування, конфлікти, помилки та ізоляція облікових записів; обране — CRUD, незмінність знімків, перенесення/копіювання, partial retry, старі посилання й ізоляція просторів; робочі простори — вибір, збереження, область API запитів і помилки. Візуальні скриншоти та перевірка відсутності shell виконані на ширині 390 px. Це не перевірка живого бекенда або нативного пристрою.
